# YKTYS25H1 – Webshop (React + TypeScript)

This project is a simple webshop developed as part of the **YKTYS25H1** course assignment.  
The focus of the project is to apply React, TypeScript, and good project structure practices, including state management, API communication, and deployment.

## Live Demo

The application is deployed on Netlify and can be accessed here:

👉 https://sockerchock.netlify.app

---

## Features

- Product list with detailed product view
- Add products to a shopping cart
- Update product quantity
- Checkout flow and order confirmation
- Responsive layout (mobile-first)
- Error handling and loading states

---

## Tech Stack

- **React**
- **TypeScript**
- **Vite**
- **Zustand** (state management)
- **Netlify** (deployment)

---

## Project Structure

- Components are used for reusable UI elements
- Pages handle page-level logic and layout
- API communication is separated into a service layer
- Global state (cart) is managed with Zustand
- TypeScript is used throughout the project for type safety
